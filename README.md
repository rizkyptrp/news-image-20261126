A Python program (stdlib only, no network) that draws a newspaper front page summing up the world news of Thursday 26 November 2026 — masthead, red date banner, a lead block on the US unveiling sweeping new tariffs on 14 partners, 54 stories across 7 regions, and a markets/Thanksgiving-football footer — as a deterministic 1024x1024 PNG.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two runs write byte-identical output (verified: same sha256).
